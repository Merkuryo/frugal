# Research: find out, compare, answer with sources

1. **Pin the question.** Rewrite it as the exact claim or comparison you must settle, plus what would change the answer.
2. **Plan sub-questions.** 2–6, each answerable on its own. One per named item when comparing.
3. **Gather cheaply.** `scout` runs searches and reads pages, returning per sub-question: the finding, the source URL, the date, ≤5 lines. Run independent sub-questions in parallel.
4. **Check against alternatives.** For each tentative answer, look for the evidence that would rule it out, not only more support.
5. **Synthesize.** You, or `thinker` at L2, combine findings. Mark conflicts and gaps explicitly.
6. **Report.** Answer first, then the reasoning in a few lines, then `Sources:`. Paraphrase; quote only when exact wording matters.
