# Frugal learn

1. **Scan this session** for: corrections the user had to make, repeated failed attempts, wasted reading (whole files, re-reads), wrong level (too deep or too shallow), and things that worked unusually well.
2. **Draft at most three rules.** Each is one line, imperative, with its trigger: `When <situation>, <do this> (because <evidence, one clause>)`. Only rules that would change future behavior in this project. No generic advice already in the frugal principles.
3. **Merge, don't pile up.** Read `.frugal/lessons.md` if it exists. Replace rules your new ones supersede, merge duplicates, and keep the file at most 40 lines.
4. **Show the diff** to the user and write it after they agree. If they are away, write it and say so.
5. **Never store** secrets, credentials, personal data or anything the user asked not to keep.
