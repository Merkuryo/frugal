# Analyze: data, numbers, logs, spreadsheets

1. **Question and metric.** What decision the analysis serves, and the number that would inform it.
2. **Inspect the shape, not the rows.** Columns, types, counts, ranges, a few samples. Never load a large dataset into the conversation.
3. **Compute with code.** Write a small script that produces the numbers. Keep it as a file so it can be rerun.
4. **Sanity-check.** Totals reconcile, units are right, outliers are explained, sample sizes are stated.
5. **Interpret.** You, or `thinker` at L2, state what the numbers mean and what they do not show.
6. **Report.** Key numbers with their source and definition, one chart or table if it helps, the script path, caveats.
